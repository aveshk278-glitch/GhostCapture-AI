# Licenses and model review

GhostCapture source code is distributed under the [Apache License 2.0](LICENSE). AndroidX, Kotlin, and Gradle use Apache 2.0. FFmpeg is invoked as an independently installed executable. Depending on how it was built, its distribution license and obligations vary. The desktop pipeline uses the encoder named `libx264` from a compatible FFmpeg distribution. No FFmpeg binaries are included. [AndroidX license](https://github.com/androidx/androidx/blob/androidx-main/LICENSE.txt) · [Kotlin license](https://github.com/JetBrains/kotlin/blob/master/license/LICENSE.txt) · [FFmpeg legal terms](https://ffmpeg.org/legal.html)

Desktop dependencies are NumPy and SciPy (BSD-3-Clause), Pillow (MIT-CMU / HPND), and optional PyTorch (BSD-style) and OpenCV 4.5+ (Apache 2.0). Wheels may include additional notices and bundled components. GPU drivers and the Android device operating system are platform prerequisites. [NumPy](https://github.com/numpy/numpy/blob/main/LICENSE.txt) · [SciPy](https://github.com/scipy/scipy/blob/main/LICENSE.txt) · [Pillow](https://github.com/python-pillow/Pillow/blob/main/LICENSE) · [PyTorch](https://github.com/pytorch/pytorch/blob/main/LICENSE) · [OpenCV](https://github.com/opencv/opencv/blob/4.x/LICENSE)

| Candidate | Published terms and availability | Decision |
| --- | --- | --- |
| ProPainter | Authors publish code and model weights under S-Lab 1.0 for noncommercial use. The temporal pipeline is designed for GPU use, with memory demand dependent on frame size and clip length. | Excluded due to the noncommercial restriction. [Upstream repository](https://github.com/sczhou/ProPainter) |

| STTN | The upstream repository has an MIT license file and links to externally hosted weights trained on YouTube-VOS. The repository instructions use the PyTorch video model. Separate grant and redistribution provenance for that exact weight artifact were unverified. | Weights excluded pending artifact-specific verification. [Code license](https://github.com/researchmm/STTN/blob/master/LICENSE) · [Checkpoint instructions](https://github.com/researchmm/STTN#completing-videos-using-pretrained-model) |
| LaMa | The upstream repository has an Apache 2.0 license file and offers a separate big-lama archive. LaMa is a spatial model with upstream CPU and GPU examples. Weight-specific redistribution terms for that archive were unverified. | Weights excluded pending artifact-specific verification. [Code license](https://github.com/advimman/lama/blob/main/LICENSE) · [Upstream checkpoints](https://github.com/advimman/lama) |
| GhostCapture neural fill | Original network and training code in this repository. The model learns from usable regions of user-supplied footage. It can use CPU, CUDA, or Apple MPS through PyTorch. | Included as opt-in local training. No externally sourced model weights are downloaded or distributed. Treat generated checkpoints as derived from the input recording. |

The Android application uses the platform's MediaProjection and codec APIs. GitHub, Kaggle and Colab are optional hosted services and are subject to their own terms.
